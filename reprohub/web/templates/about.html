它做什么

  • 聚合：每小时从 PubMed、Europe PMC、bioRxiv/medRxiv、Crossref（核心期刊）、期刊与媒体 RSS 等来源采集，按 DOI / PMID / URL / 标题指纹去重；多个来源收录同一篇时合并为一条并记录「另外 N 个来源也收录」。
  • 分类与门槛：{{ topics|length }} 个主题覆盖生殖与辅助生殖全领域（见 主题）。属于该领域是收录门槛；横切主题（组学方法、AI、动物模型）单独命中不算在领域内。
  • 重点偏好（只加权，不是门槛）：
      {% for r in preferences %}
    • {{ r.label }} +{{ r.weight }}
      • {% endfor %}
    偏好分乘以 {{ selection.scoring.preference_weight }} 后加到最终分（上限 +{{ selection.scoring.preference_cap }}）。未命中任何偏好的领域内内容照常收录。
  • 期刊等级与影响因子：config/journals.yaml 把期刊分为 CNS / 大子刊 / 综合顶刊 / 领域顶刊 / 普通 / 高发文量 OA 刊，分别加权 +12 / +8 / +6 / +4 / 0 / −3；影响因子为{{ IF_SOURCE }}，未收录期刊显示「IF 未收录」且不加减分。顶刊单独有 顶刊 页、/feed/top.xml 与专门的 PubMed / Crossref 来源。
  • 评分与入选：模型按新颖性、严谨性、领域影响、领域相关、转化价值五个维度评 0-100，加偏好与来源等级修正得最终分；入选阈值按来源等级为 {{ selection.scoring.select_threshold }}。
  • 文献解读：最终分 ≥ {{ selection.interpret.auto_min_score }} 的文献自动生成结构化中文解读（背景 / 设计 / 发现 / 多组学视角 / 意义 / 局限 / 术语），其余可在条目页按需生成。
  • 事件与热度：近 {{ selection.cluster.window_days }} 天内相关条目聚为事件；热度按独立来源计（48 小时内每来源一次，24 小时减半），同一媒体多次报道不重复计热。
  • 日报 / 周报 / 月报：日报由规则编纂，周报月报从日报汇编，模型只写总述与栏目导读。
  • 阅读管理：未读 / 在读 / 已读、星标、稍后读、五星评分、标签、Markdown 笔记、按课题分集合；可导出 Markdown / JSON / CSV / BibTeX。
  • 推送：日报与高分条目可推到文件（Obsidian 目录）、Server 酱、Bark、ntfy、飞书、企业微信、钉钉、Telegram、邮件或任意 Webhook。
  • 对外出口：RSS / JSON API / llms.txt。
